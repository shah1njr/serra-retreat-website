# SERRA — A Sanctuary Within Stone

A small, original responsive website inspired by the SERRA brief. The canyon scene is drawn with CSS gradients and shapes; it does not download or reuse the source website's photographs or videos.

## Run it

Open `index.html` in a browser. No build tools or account keys are required. Google Fonts are optional; the page falls back to system fonts if they cannot load.

## What is included

- Responsive four-part retreat story with a scroll-reactive CSS canyon scene.
- Keyboard-accessible menu dialog and navigation links.
- Contact enquiry dialog that opens an email draft (replace the demo recipient in `script.js` before publishing).
- Stillness mode, reduced-motion support, and a skip-animation link.
- No backend, login, booking, or payment flow. The enquiry form prepares an email draft; it does not send or store submissions.
